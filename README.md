# React E-Commerce Store 🛒

This is a responsive e-commerce front-end application built with **React.js** and **Tailwind CSS**. It features product browsing, cart functionality, search, and navigation.

## 🔧 Tech Stack

- React.js
- Tailwind CSS
- React Router DOM
- Context API (Cart Management)
- Fakestore API for dummy products

## 📦 Features

- ✅ Home page with hero section and featured products
- ✅ Product listing with dynamic cards
- ✅ Add to Cart functionality using Context API
- ✅ Search bar for filtering products
- ✅ View All Products link to full product list
- ✅ Responsive design

## 🖥️ Folder Structure

src/
│
├── components/ # Reusable UI components like ProductCard, Hero, Header
├── pages/ # Home, Products, Cart pages
├── Context/ # CartContext using Context API
├── CustomHook/ # useProducts hook for fetching product data
├── App.js # Main app routing and layout
├── main.jsx # Entry point
└── index.css # Tailwind CSS
